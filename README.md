## What you can ask about Steam

- Using TrendsConnector, show me Steam concurrent player data for Elden Ring.
- What are the most played games on Steam right now?
- How has the Steam player count for "Elden Ring" changed over 2 years?
- Is "Counter-Strike 2" growing or losing players?

Start with "Using TrendsConnector" so your AI uses the connector instead of a web search.

## What it covers

- Concurrent players
- Most played now

| Data | Ask with | What it measures |
|---|---|---|
| History and growth | a keyword: game display name e.g. elden ring (first steam search result) | Steam concurrent players (monthly) |
| Live board: Steam Most Played | no keyword | Top games by concurrent live players |

## How to ask

Pass the game's display name, such as Elden Ring. The first Steam search result is used. Most played right now needs no keyword.

**Good to know:** This is player counts. It does not return reviews, price, or sales.

## FAQ

**Do I need a Steam app ID?**  
No. Pass the game's display name. The first Steam search result is used.

**Can I see what is most played right now?**  
Yes. That list needs no keyword.

**Is the Steam connector free?**  
Yes. The free plan has 100 requests a month and includes every source. No credit card. Paid plans start at $19 a month for 1,000 requests.

**Which AI apps work with it?**  
Claude, ChatGPT, Cursor, VS Code, Claude Code, Grok, Muse, Perplexity, Gemini, Copilot, Windsurf and any app that supports MCP connectors.
